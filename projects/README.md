# Project Images Directory

Place your project screenshot or mockup images here!

For example:
- `flowstate.png`
- `komorebi.png`
- `pulse.png`

Then update `src/data/portfolioData.ts`:
```ts
{
  id: "project-1",
  title: "FlowState AI — Ambient Voice Dictator",
  imageUrl: "/projects/flowstate.png",
  // ...
}
```

Any image in this folder can be referenced with the path `/projects/<filename>`.
You can also use external image URLs (e.g. Unsplash or your CDN).
